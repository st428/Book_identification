# 已知限制

本系统定位为书架智能巡检和索书号识别辅助工具，不是完全自动化馆藏管理系统。

## 不处理的范围

- 不连接数据库，不做馆藏比对。
- 不自动判断缺失书籍。
- 不把黄色补框直接作为红色错架依据。
- 不默认使用自训练 OCR 模型，Web 稳定版固定官方 PaddleOCR。

## 可能需要人工复核的情况

- 图片明显倾斜、远距离拍摄、书架边缘透视严重。
- 索书号被红色标签、污渍、反光、阴影或手遮挡。
- 书号本身模糊、过小、过亮或过暗。
- 最左侧、最右侧或半本书入镜导致 crop 不完整。
- 很薄的书、多个书号距离过近、书脊之间存在空隙。
- 非标准索书号、手写书号、字体过于特殊。
- OCR 置信度低、格式不完整、系统标黄的结果。

## 使用建议

- 日常先用普通模式。
- 黄色较多、crop 可疑或 OCR 失败时，再用精细模式。
- 出现姿态提示时，优先重新拍摄：手机尽量平行书架，书号区域保持清晰完整。
- 红色结果表示疑似错架建议，不代表系统完成了馆藏缺失或馆藏正确性判断。
